# resistor-bands

Four-band read — and the inverse: ohms back to colors.

Live: [https://robertstreize.com/lab.html#resistor](https://robertstreize.com/lab.html#resistor) · part of [treize-lab](https://github.com/streboreziert/treize-lab)

## Extra

Forward 4-band plus inverse search (closest preferred value) and optional 5-band (3 digits).

## Install

```bash
python3 -m pip install -e .
resistor_bands brown black red gold && resistor_bands --ohms 4700
```
